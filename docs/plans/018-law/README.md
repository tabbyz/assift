### 3.1 氏名・住所・電話番号の省略

法 11 条ただし書: 広告に「請求があれば遅滞なく（書面または電子メールで）提供する」旨を表示し、実際に遅滞なく提供できる体制があれば、
一部の事項を省略できる（施行規則。価格などの金銭を全部表示していることが前提）。

- **住所・電話番号**: 省略する（個人事業主で一般的。消費者庁の解説・各社の解説で異論が無い）。
  請求が来たら数日以内にメールで返す。返せる住所・電話番号（バーチャルオフィス・050 番号でもよい）を公開前に用意しておく
- **氏名**: 表示する（`LAW.sellerName`）。
  - 法文上は氏名も省略の対象に読めるが、「省略できるのは住所と電話番号だけ」とする解説も多く、Stripe の審査で差し戻される例がある
  - 表示するなら**戸籍上の氏名**（または商業登記した商号）。屋号・通称・ハンドルネームだけでは足りない
  - 省略に切り替えるときは `sellerName` を `null` にする（「ご請求があれば…」の表示になる）
